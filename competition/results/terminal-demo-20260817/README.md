# Judge-facing five-minute competition demo

`demo-terminal-5min.mp4` presents the submission in judging order: system
architecture, real-time changes and formal board results, IP-based inter-guest
communication and restart recovery, AI closed-loop control, and engineering
evidence. It is generated by
[`render-terminal-demo.ps1`](../../video/render-terminal-demo.ps1) from the
checked-in VHS tapes, narration timeline, retained UART log, machine JSON, and
the archived bundle's fail-closed verifier.

The terminal uses Hack for readable command and result rendering. The retained
physical-board UART section runs at 4× and remains visibly labeled. Host-side
analysis and verification execute during recording. Exact scene timing, claim
boundaries, and rubric mapping are documented in
[`video-storyboard.md`](../../video-storyboard.md).

Generated integrity files:

- `video-manifest.json` records the video hash, source HEAD and worktree state,
  VHS image digest, acceleration, and hashes of production and evidence inputs.
- `SHA256SUMS` contains the final MP4 hash.
- `ffprobe.json` records duration, codecs, dimensions, frame rate, and audio
  properties.

The older `current-source-smoke-20260813` bundle remains unchanged so its
frozen checksum and provenance contracts continue to verify.
